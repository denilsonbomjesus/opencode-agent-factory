# Repository AI Rules
- Antes de codar, leia apenas os arquivos necessários para a tarefa.
- Nunca use `any` em TypeScript.
- Não quebre contratos públicos sem atualizar consumidores e testes.
- Teste antes de concluir; PR sem testes deve ser recusado.
- Se houver incerteza sobre regra de negócio, pare e peça confirmação.
- Rode os comandos padrão do repositório: testes, lint, format e validação de segurança.
